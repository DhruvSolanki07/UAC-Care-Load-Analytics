# UAC Care Load Analytics

## Overview

An analytical dashboard for examining system load,
transfers, discharges, and care-load pressure in the
Unaccompanied Children care pipeline.

## Objectives

- Quantify system care load
- Compare CBP and HHS care load
- Analyze transfers and discharges
- Identify periods of elevated load pressure
- Evaluate data quality
- Explore time-series forecasting

## Dataset

The dataset contains observations from January 2023
through December 2025.

## Technology Stack

- Python
- Pandas
- NumPy
- Plotly
- Scikit-learn
- Statsmodels
- Streamlit
- Jupyter
